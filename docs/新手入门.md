# SkillDB 新手入门与全目录指南

欢迎使用 **SkillDB System** —— 面向想要学习 AI 变现人群的开源 AI Skills 通关工具箱。

---

## ⚡️ 快速开始

### 直接在对话中使用智能路由器 `/sk`

你不需要记住复杂的技能名称，直接在 Agent 中输入：

```text
/sk 我是国内小白，想从零开始配置 ChatGPT 和使用 Codex 编程，怎么操作？
```

`/sk` 路由器会自动分析上下文，调度匹配的专业 Skill 输出极简通关路线。

---

## 📚 核心技能全目录

| 技能指令 | 技能名称 | 核心用途说明 |

| **`/gula-vpn-clash-guide`** | **机场与 Clash 全指南** | 引导访问古拉防丢失发布站、订阅套餐及 Windows/macOS/Android/iOS 安装 Clash |
| **`/chatgpt-installer-skill`** | **ChatGPT 全平台安装** | 突破 Windows 区域限制一键安装官方桌面版，提供 macOS DMG 下载 |

## 🛠️ 构建与维护

开发或修改技能后，可以在 `tools/` 目录下运行工具链进行校验与打包：

```bash
cd tools/

# 1. 运行 Linter 检查所有 Skill 的规范与 YAML
python validate_skills.py

# 2. 打包生成发布目录 dist/skills/
python build_skills.py
```
