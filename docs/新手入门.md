# SkillDB 新手入门与全目录指南

欢迎使用 **SkillDB System** —— 面向创业者、开发者与内容创作者的模块化 AI Skills 工具箱。

---

## ⚡️ 快速开始

### 方式一：直接在对话中使用智能路由器 `/sk`

你不需要记住复杂的技能名称，直接在 Agent 中输入：

```text
/sk 我做少儿编程课，已经有 40 个付费学员，但续费率很低。我需要判断问题出在产品、定价，还是找错了客户。
```

`/sk` 路由器会自动分析上下文，调度匹配的专业 Skill 输出诊断矩阵。

| `/sk-knowledge` | 知识库 | 本地与网络知识原子 (atoms.jsonl) 检索与挂载 |

## 🛠️ 构建与维护

开发或修改技能后，可以在 `tools/` 目录下运行工具链进行校验与打包：

```bash
cd tools/

# 1. 运行 Linter 检查所有 Skill 的规范与 YAML
python validate_skills.py

# 2. 打包生成发布目录 dist/skills/
python build_skills.py

# 3. 桥接同步至系统全局 Agent 目录
python bridge_sync.py
```
