## 🌐 第一步：配置 VPN 网络 (解决阻断与搭建 4 步法)

### 1.1 关键细节与防丢失主站机制
> [!IMPORTANT]
> **防丢失主站特别说明**：
> `https://古拉.com/`（在部分浏览器转换为 Punycode `https://xn--w4r430a.com/`）是一个**防丢失导航发布主站**。
> 由于科学上网节点域名极易被屏蔽，**主站本身不直接提供节点**（因此在命令行进行 `ping` 或 `curl` 提示拦截阻断是正常现象）。主站的核心功能是**展示最新的二级真正入口网址**。**必须由用户自己在浏览器中手动打开**并点击最新入口进行跳转。

### 1.2 详细 4 步搭建流程
1. **步骤 1：访问防丢失主站，获取二级最新入口**
   - 在浏览器中手动输入 `https://古拉.com/`。
   - 若遇到阻断提示打不开，请在系统设置中将 DNS 修改为公共 DNS（如阿里云 `223.5.5.5` 或 `1.1.1.1`），或切换手机 5G 移动网络打开。
   - 打开页面后，点击显眼的 **“最新可用入口”** 按钮，跳转到真正的机场注册与登录平台。
2. **步骤 2：注册账号与购买套餐**
   - 在二级入口网站注册电子邮箱账号（建议使用 Gmail, Outlook, QQ 邮箱）。
   - 登录后台进入“商店”，选择适合的套餐进行支付。
   
   > [!WARNING]
   > **避坑提醒**：第三方机场存在服务中断或运营风险，强烈建议**优先选择月付（按月订阅）**，切勿大额充值多年！

3. **步骤 3：下载客户端与获取订阅链接**
   - 在平台控制台后台下载对应系统的客户端软件：
     - **Windows**: 下载 [Clash Verge Rev x64 安装包](https://github.com/clash-verge-rev/clash-verge-rev/releases)
     - **macOS**: 下载 [Clash Verge Rev for Mac](https://github.com/clash-verge-rev/clash-verge-rev/releases) 或 ClashX Meta
     - **Android**: 下载 [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid/releases)
     - **iOS**: 使用美区 Apple ID 在 App Store 下载 Shadowrocket (小火箭)
   - 在后台首页找到“快速导入”区域，点击 **“一键导入 Clash”** 或 **“复制 Clash 订阅链接”**。
4. **步骤 4：客户端导入与最终开启代理**
   - 打开 Clash 软件，在“订阅 (Profiles)”页面粘贴订阅链接并点击导入。
   - 鼠标单击选中导入的配置。
   - 进入“代理 (Proxies)”页面，模式切换为 **规则模式 (Rule)**。
   - 进入“设置 (Settings)”页面，开启 **系统代理 (System Proxy)**。
   - **至此，VPN 代理网络才算真正配置搭建完成！**

## 💻 第二步：安装 ChatGPT 官方桌面版客户端 (突破区域限制)

### 2.1 macOS 系统安装细节
- 直接下载官方离线 DMG 安装包：[https://persistent.oaistatic.com/codex-app-prod/ChatGPT.dmg](https://persistent.oaistatic.com/codex-app-prod/ChatGPT.dmg)
- 下载完成后双击挂载，将 `ChatGPT.app` 拖入 `Applications`（应用程序）文件夹即可完成安装。

### 2.2 Windows 系统安装细节（突破“在你所在的地区不可用”限制）
> [!IMPORTANT]
> **避坑原因**：OpenAI 在微软商店 (Microsoft Store) 针对中国大陆等地区隐藏了 ChatGPT 桌面版，直接搜索会提示“在你所在的地区不可用”。

#### 🛑 核心前提：修改 Windows 系统区域为“美国” (必须执行)
1. 按快捷键 **Win + I** 打开设置。
2. 进入 **时间及语言** -> **区域**。
3. 将 **“国家或地区”** 下拉框修改为 **美国 (United States)**。（*修改即时生效，无需重启电脑*）。

#### 方法 A：使用 Winget 命令一键安装（官方推荐）
修改区域后，右键开始菜单打开 **“终端 (管理员)”** 或 **PowerShell (管理员)**，运行：
```powershell
winget install --id=9NT1R1C2HH7J -e
```
提示协议输入 `Y` 回车，程序会自动从微软官方服务器抓取并完成安装。

#### 方法 B：离线包安装 (`.msixbundle`)
如果商店被彻底禁用或 Winget 报错：
1. 打开在线抓包网站：[store.rg-adguard.net](https://store.rg-adguard.net/)
2. 下拉框选 **`ProductId`**，搜索框输入产品 ID **`9NT1R1C2HH7J`**，右侧选 **`Retail`** 搜索。
3. 找到以 **`.msixbundle`** 结尾的文件（约 200MB+）下载。
4. 在管理员 PowerShell 中运行：
```powershell
Add-AppxPackage -Path "C:\下载路径\ChatGPT.msixbundle"
```
