# ChatGPT 全流程通关新手教程

本教程旨在为新用户提供一份从零开始、通俗易懂的 **ChatGPT 全流程上手指南**。

---

## 📌 教程三大核心步骤

```
第一步：配置 VPN 网络 ➔ 第二步：安装 ChatGPT 客户端 ➔ 第三步：购买账号与 Plus 订阅
```

---

## 🌐 第一步：配置 VPN 网络

国内直接访问 OpenAI 服务会被封锁或阻断，因此首先需要配置稳定顺畅的网络代理环境：

1. **访问服务商网站**：
   打开 `https://古拉.com/`（在部分浏览器中转码显示为 `https://xn--w4r430a.com/`）。若无法直接加载，请修改本地 DNS 为 `223.5.5.5`（阿里 DNS）或 `1.1.1.1`。
2. **注册与购买订阅**：
   在网站注册账号并登录后台，进入“商店/购买订阅”，按月购买适合自己的网络套餐（推荐月付以规避长周期风险）。
3. **下载安装 Clash 客户端**：
   - **Windows**: 下载 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases) 安装包。
   - **macOS**: 下载 [Clash Verge Rev for Mac](https://github.com/clash-verge-rev/clash-verge-rev/releases) 或 ClashX Meta。
   - **Android**: 下载安装 [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid/releases)。
   - **iOS**: 使用美区 Apple ID 下载 Shadowrocket。
4. **导入并连接代理**：
   在古拉网站后台点击“一键导入 Clash”，在客户端中勾选导入的节点配置，切换为 **规则模式 (Rule)** 并勾选 **系统代理 (System Proxy)**。

---

## 💻 第二步：安装 ChatGPT 官方桌面版客户端

根据你的操作系统采取对应的安装策略：

###  macOS 系统用户
1. 直接点击官方离线 DMG 包下载地址：[https://persistent.oaistatic.com/codex-app-prod/ChatGPT.dmg](https://persistent.oaistatic.com/codex-app-prod/ChatGPT.dmg)
2. 下载完成后双击挂载，将 `ChatGPT.app` 拖入 `Applications`（应用程序）文件夹即可完成安装。

---

### 🪟 Windows 系统用户（突破“在你所在的地区不可用”限制）
由于 OpenAI 在微软商店隐藏了中国区域的应用，请严格按以下步骤处理：

#### 🛑 核心前提：将 Windows 系统区域修改为“美国”
1. 按快捷键 **Win + I** 打开设置。
2. 进入 **时间及语言** -> **区域**。
3. 将 **“国家或地区”** 下拉框修改为 **美国 (United States)**。（*修改即时生效，无需重启电脑*）。

#### 方法 A：使用 Winget 命令一键安装（官方推荐）
右键点击开始菜单打开 **“终端 (管理员)”** 或 **PowerShell (管理员)**，运行：
```powershell
winget install --id=9NT1R1C2HH7J -e
```
提示协议输入 `Y` 回车即可自动完成全套安装。

#### 方法 B：抓取离线包安装 (`.msixbundle`)
1. 打开在线抓包网站：[store.rg-adguard.net](https://store.rg-adguard.net/)
2. 下拉框选择 **`ProductId`**，搜索框输入产品 ID **`9NT1R1C2HH7J`**，右侧选 **`Retail`** 搜索。
3. 找到以 **`.msixbundle`** 结尾的文件（约 200MB+）下载。
4. 在管理员 PowerShell 中运行：
```powershell
Add-AppxPackage -Path "C:\下载路径\ChatGPT.msixbundle"
```

## 🛒 第三步：购买账号与 Plus 订阅接码

完成网络配置和软件安装后，即可进行账号获取与 Plus 升级：

1. **选择低价优质账号与代充**：
   - 打开 AI 资源聚合平台 `https://aiprobe.top/`。
   - 使用技能系统中的 `/aiprobe-plus-buyer` 智能挑选包含退款质保、售价最低的 ChatGPT Plus 成品号、官方代充或兑换码。
2. **接码渠道验证**：
   - 注册或升级新账号遇到短信手机号验证（SMS OTP）时，接入 SMS 接码渠道（SMS-Activate 或 5SIM）。
   - 租用 OpenAI 专属号码，自动轮询获取 6 位数短信验证码，完成账号激活与 Plus 会员特权解锁。
