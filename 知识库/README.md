# 知识库 (Knowledge Base System)

本目录收录了 Skill System 的结构化底层知识，用于辅助 Agent 进行 RAG (检索增强生成)、上下文关联及方法论支撑。

## 目录说明

1. **原子库 (`原子库/atoms.jsonl`)**：
   包含结构化的知识原子数据（JSONL 格式），适合导入向量数据库（如 Qdrant / Ollama / Chroma）构建 RAG。
2. **Skill 知识包 (`Skill知识包/`)**：
   存放各领域 SOP、流程图及分析模板。
3. **概念词典 (`概念词典/`)**：
   涵盖商业、内容创作、AI 自动化与技术架构的高频专业词条定义。
