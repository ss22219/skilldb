# 战略决策 Skill (/sk-decision)

本 Skill 帮助创业者在面临重大业务分叉口（如：离职创业、推出新产品、更换赛道）时，排除情绪干扰，进行理性决策分析。

---

## ⚖️ 决策评估矩阵

| 评估维度 | 核心考量指标 | 风险防范 |
| :--- | :--- | :--- |
| **下行风险 (Downside)** | 最坏情况下损失多少资金与时间？ | 是否在可承受范围内？ |
| **上行空间 (Upside)** | 成功后的复利效应与天花板 | 是否具备规模化扩展性？ |
| **MVP 验证速度** | 验证该想法需要几天/多少成本？ | 能否在 2 周内验证第一笔付费？ |

---

## 使用示例

```bash
/sk-decision 我目前在全职带团队，想出来做面向 AI 领域的个人顾问，我该如何评估风险与第一步行动？
```
