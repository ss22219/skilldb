# 内容策划 Skill (/sk-content)

本 Skill 专门解决内容创作者与品牌方“不知道写什么”、“完播率低”与“互动转化差”的难题。

---

## 🎯 内容产出模型

```
[前 3 秒黄金 Hook] ➔ [反直觉事实/痛点拉满] ➔ [核心干货/案例] ➔ [强行动唤醒 CTA]
```

### 核心方法：
- **前 3 秒 Hook**: 痛点现象 + 颠覆常规认知 + 给出具体解决方案预告。
- **情绪共鸣点**: 拒绝干瘪讲道理，用场景和细节代入情绪。
- **评论区诱饵 (Engagement Hook)**: 预留争议话题或资料包领取口子。

---

## 使用示例

```bash
/sk-content 我想讲“普通人别急着做个人 IP”，这个选题怎样做成高完播率的短视频脚本？
```
