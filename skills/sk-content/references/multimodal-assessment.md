## 证据采集

完整成片评审至少需要：

- 原始视频或无二次压缩版本；
- 带词级时间戳的语音转录；
- 前 3 秒密集关键帧、全片均匀抽帧和镜头切换帧；
- 视频分辨率、帧率、时长、音轨、响度和静音比例；
- 可获得时加入曝光、清晰度、噪声、削波、语速、停顿、字幕和镜头切换数据；
- 发布后的点击、3 秒留存、平均观看、完播、互动、关注、私信和成交数据。

先运行 `scripts/prepare_video_evidence.py`。再用可用的视觉模型查看关键帧；用转录工具生成词级时间戳。工具不可用时保留缺失项，不用主观猜测填满表格。

抽帧最低要求：

- 0–3 秒：至少检查 0.5、1.5、3 秒；
- 3 秒以后：按视频长度均匀抽取；
- 发生场景切换、字幕变化、产品展示或人物状态明显变化时追加关键帧。

## 制作层五维评分

每个维度包含 5 个观察项，每项 0–4 分。

### 文案与信息（20 分）

1. 受众与任务明确；
2. 开头具体并兑现；
3. 核心观点清楚；
4. 证据、案例与方法充分；
5. 结构、结尾和行动完整。

### 视觉表达（20 分）

1. **可见性**：主体、字幕和关键物体清楚。
2. **构图**：画面层级、留白、视线和比例服务主题。
3. **光线与色彩**：曝光、肤色、对比和色彩稳定。
4. **信息支持**：B-roll、演示、图示或字幕帮助理解。
5. **节奏**：镜头变化有目的，不乱切，也不长期停滞。

工作环境只按“是否干扰信息、是否符合角色与主题”评分。简陋不等于不可信，奢华也不自动加分。

### 音频质量（20 分）

1. 人声清晰、可理解；
2. 响度稳定，峰值没有明显削波；
3. 背景噪声、混响和风噪不干扰；
4. 音乐、音效与人声比例合理；
5. 静音、断句和剪辑没有技术性突兀。

响度数值用于发现问题，不机械决定好坏。平台、音乐类型和内容情绪不同，需要结合听感判断。

### 声音与镜头表现（20 分）

1. 语速与信息密度匹配；
2. 停顿、重音、音高和能量有变化；
3. 情绪与文案一致；
4. 视线、表情、姿态和手势自然；
5. 状态投入、稳定，并与创作者定位一致。

不要因口音、音色、年龄、外貌或残障扣分。只评估是否清楚、自然、适配内容和目标受众。

### 音画协同（20 分）

1. 前 3 秒文案、画面、字幕和声音指向同一件事；
2. 重要词与画面证据在时间上对应；
3. 字幕准确、易读，不遮挡关键区域；
4. 音乐、节奏、剪辑和情绪一致；
5. 结尾画面与下一步行动一致。

## 结果层映射

制作层提供证据，结果层回答效果：

| 制作证据 | 主要映射 |
|---|---|
| 开头、构图、语速、剪辑、声音清晰度 | 注意力 |
| 处境语言、表情、情绪、场景与频道匹配 | 同频 |
| 证据、边界、状态一致、环境适配、音画一致 | 信任 |
| 方案展示、风险说明、CTA 与承接画面 | 成交 |
| 稳定观点、视觉语言、声音风格、栏目与记忆点 | IP |

制作分高不代表结果分必然高。技术精良但内容空洞，应表现为制作层高、结果层低。

## 时间轴评审

按以下节点输出证据：

- **0–3 秒**：用户看到什么、听到什么、预测接下来会得到什么。
- **首次流失风险点**：第一次出现重复、模糊、停顿过长或音画冲突的时间。
- **价值兑现点**：第一次给出有效答案、证据或演示的时间。
- **信任增强点**：出现边界、案例、过程或一致性证据的时间。
- **信任泄漏点**：承诺过大、证据不足、状态或音画冲突的时间。
- **行动点**：用户被要求做什么，阻力有多大。

每条问题至少给出一个时间码和修复动作。

## 数据校准

模型评分属于发布前预测，平台数据属于发布后证据。使用同一创作者、同一平台、相近主题的历史内容校准：

- 点击或 3 秒留存校准注意力；
- 平均观看、完播和二次观看校准节奏；
- 评论语义、收藏和分享校准同频与价值；
- 主页访问、关注和复访校准信任与 IP；
- 私信、线索、预约和购买校准成交。

至少积累 30 条作品后再调整评分权重。不要用跨平台平均值代替个人基线。
