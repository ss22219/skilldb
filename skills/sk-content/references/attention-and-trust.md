## 内容竞争的对象

短视频与其他内容竞争用户有限的注意力，但获得注意力只完成了第一步。完整路径为：

`看见 → 停留 → 同频 → 相信 → 行动 → 记住`

不同内容可以只承担其中一段。获量内容负责扩大入口，同频内容负责筛选关系，信任内容负责降低不确定性，成交内容负责推动决定，IP 内容负责积累长期记忆。

## 注意力机制

常见有效机制：

- **自我相关**：与“我的问题、身份、收益或风险”直接相关。
- **预测误差**：反常识、不可预测结果或违反常见模式。
- **信息缺口**：用户知道缺了一个关键答案，并相信继续看能得到答案。
- **冲突与变化**：观点冲突、选择冲突、前后反差或目标与现实的距离。
- **情绪唤醒**：好奇、惊讶、希望、焦虑、愤怒等提高注意强度。
- **具体性**：人物、数字、动作、场景比抽象概念更容易被处理和记忆。
- **处理流畅性**：清晰画面、可听声音、合适语速和简单句降低理解成本。

每次使用注意力机制，都检查三个问题：

1. 是否吸引了目标用户，而非无关流量？
2. 正文是否兑现了开头？
3. 这种方法是否损害长期信任？

## 同频机制

同频内容服务特定频道，不追求所有人接受。高质量同频通常包含：

- 准确说出一类人的处境与隐性情绪；
- 使用这类人熟悉的语言、案例和问题；
- 明确站在他们的处境中，而非居高临下地教育；
- 确认其合理信念，同时挑战一个具体行为；
- 让转发或评论成为身份表达。

同频的风险是封闭回音室。评分时检查内容是否为了讨好群体而牺牲事实。

## 信任判断

人的确会利用有限信息快速预测一个人是否值得合作。评分时把信任拆成三层：

1. **感知可信**：声音、语速、表情、画面、环境、穿着和投入状态带来的第一印象。
2. **主张可信**：观点是否具体，推理是否连贯，是否承认边界和代价。
3. **验证可信**：来源、案例、过程、结果、第三方证明和长期一致性。

高标准内容不能只追求第一层。镜头表现很好但没有证据，属于“看起来可信”；表达朴素但证据充分，可能具有更高的验证可信度。

环境和个人状态按“是否干扰信息、是否与角色承诺一致”来判断。不要把贫富、口音、年龄、外貌、残障或审美偏好当作品格证据。

## 不可信感泄漏

重点检查：

- 承诺大于证据；
- 把别人的案例说成自己的；
- 只展示结果，隐藏成本、时间与失败条件；
- 使用假精确数字或无法追溯的权威；
- 身份、观点和产品前后不一致；
- 急迫推销、虚假稀缺、贬低受众；
- 回避用户最关心的风险；
- 语速、音质、视线或环境持续干扰理解；
- 模仿热门表达，缺少自己的判断。

每次指出“不可信感”时，必须说明具体线索、可能造成的预测，以及可以怎样修复。不要给人格定性。

## 外部教程入库方法

把“爆款 8 大元素”或收集到的文案方法先视为候选规则，不直接当作普遍真理。每条素材整理成规则卡：

| 字段 | 内容 |
|---|---|
| 规则名 | 方法的简短名称 |
| 原始来源 | 作者、链接、课程或原话 |
| 适用平台 | 抖音、小红书、视频号等 |
| 内容任务 | 获量、同频、信任、成交或 IP |
| 心理机制 | 自我相关、预测误差、信息缺口、情绪、身份等 |
| 预期指标 | 点击、停留、完播、互动、私信、成交等 |
| 适用边界 | 什么情况下有效 |
| 反例 | 什么情况下会伤害效果或信任 |
| 证据等级 | 个人经验、多个案例、对照实验或稳定数据 |

同类规则合并，冲突规则按内容任务和适用边界并存。只有提供薛辉“8 大元素”的原始清单或可靠出处后，再逐条映射，避免凭记忆补全。
