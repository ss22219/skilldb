只在用户提交了尚未整理的新视频、录音、图片、白板或转录时读取本文件。

## 输入分层

将素材分为：

- 原始视频、音频、图片和白板照片；
- 自动转录或 OCR 文本；
- 人工校订文本；
- 作者明确提出的方法；
- 案例、数据与结果；
- 二次总结和 AI 推导。

始终保留原始材料与加工版本的对应关系。自动转录不是原话证据，未经人工确认不得用于精确引用。

## 转录清洗

1. 保留原始转录；
2. 复制生成清洗版；
3. 修正明显错字、断句和专有名词；
4. 不擅自补充缺失观点；
5. 不确定处标记时间码或白板区域；
6. 将“事实陈述”“个人经验”“方法建议”“案例结果”分开。

对白板图片同时保存：

- 完整白板图；
- 分区截图；
- OCR 文本；
- 图形关系描述；
- 人工确认后的结构化文本。

每张卡只保存一条可检验规则：

```text
心理机制：

失效条件：
反例：

建议进入的 K 等级：

```

不要把一句有感染力的话直接升级成评分规则。规则必须能够观察、评分或通过数据验证。

## 证据等级

| 等级 | 证据 |
|---|---|
| A | 多轮对照测试或稳定数据支持 |
| B | 多个独立案例与明确机制支持 |
| C | 单一创作者的重复经验或多个弱案例 |
| D | 单次经验、个人主张或待验证推测 |

D 级只能进入素材库。C 级可进入练习建议。B 级可进入评分参考。A 级才适合成为晋级考试的硬门槛。

## 冲突处理

遇到“必须做爆款”和“只服务同频用户”等冲突时：

1. 标记双方内容任务；
2. 标记平台和受众阶段；
3. 找出各自预测的指标；
4. 保留适用边界；
5. 设计同账号的小样本对照；
6. 用数据决定个人权重，不删除另一条规则。

多数冲突来自任务不同，不需要强行选一个普遍答案。

## 进入课程与考试

规则进入 K12 系统需依次经过：

`素材 → 规则卡 → 证据分级 → 作品试验 → 数据复盘 → 课程候选 → 评分项 → 考试门槛`

每次修改考试门槛都记录版本、原因、样本量和受影响等级，保证新旧学员可以追溯。
